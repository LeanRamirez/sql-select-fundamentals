# sql-select-fundamentals

1- En producción es mala practica usar "SELECT *" por que consume tiempo, memoria y dinero. No es solo cuestión de sintaxis sino de eficiencia.
2- Los alias son importantes para un stakeholder no tecnico por que modifica el nombre de la columna a un titulo que la persona entienda, se modifica el nombre técnico de la columna por un nombre mas grafico.
